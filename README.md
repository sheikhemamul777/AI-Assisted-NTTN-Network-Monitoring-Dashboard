# AI-Assisted NTTN Network Monitoring Dashboard

An end-to-end web application designed to monitor telecom network performance, visualize network paths, and provide predictive traffic forecasting using machine learning.

🌐 **Live Demo:** [AI-Assisted NTTN Network Monitoring Dashboard](https://ai-assisted-nttn-network-monitoring-k5oa.onrender.com)

## 🚀 Key Features
* **Real-time Performance Monitoring:** Track telecom network parameters and speed metrics.
* **Path & Data Visualization:** Interactive dashboards to analyze network conditions.
* **Predictive ML Forecasting:** Integrated machine learning model (`summit_enterprise_model.pkl`) to predict future network speeds and traffic trends.
* **Web Interface:** Built with Python Flask for a smooth and interactive user experience.

## 🛠️ Technologies Used
* **Backend:** Python, Flask
* **Machine Learning & Data Analysis:** Scikit-Learn, Pandas, NumPy, Jupyter Notebook
* **Frontend:** HTML, CSS, JavaScript (via Flask templates)
* **Deployment:** Render

## 📁 Project Structure
* `app.py`: Main Flask application file.
* `summit_enterprise_model.pkl`: Trained machine learning model for predictions.
* `Telecom_Network_Data.csv`: Dataset containing historical network performance parameters.
* `Telecom_Network_Speed_Prediction.ipynb`: Jupyter notebook used for data analysis and model training.
* `requirements.txt`: List of required Python packages and dependencies.
* `templates/`: HTML templates for the web interface.
